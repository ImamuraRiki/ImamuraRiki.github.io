# Portfolio site — notes for Claude Code

Static site (plain HTML/CSS/JS, no build step) published on GitHub Pages at https://imamurariki.github.io/ (repo `ImamuraRiki/ImamuraRiki.github.io`, branch `main`, root). Owner: Riki Imamura.

- Content lives only in `data/`: `works.js` (all works; drives index + `work.html?id=`), `profile.js` (About), `site.js` (name, nav, contact, `baseUrl`), `i18n.js` (UI strings). Schema is documented in the header comment of each file.
- Bilingual: any text field is either a plain string (same in both languages) or `{ en, ja }`; paragraph fields use `{ en: [...], ja: [...] }`. English is the default; the choice is stored in `localStorage["lang"]`. Work titles are proper nouns and are never translated: write them as plain English strings (`workTitle()` in main.js uses `en` even if an object is given).
- `assets/js/main.js` renders every page from that data and re-renders in place on language switch; HTML files are thin shells (`<body data-page="...">`).
- Fonts: Latin uses system Helvetica Neue/Helvetica/Arial (never bundle Helvetica). Japanese uses a subsetted, renamed Source Han Sans JP ("Han Sans JP Web", OFL — the name "Source" must not be used for modified files). `assets/css/fonts.css` is generated by `tools/subset-font.py`.
- Images: `images/works/<work-id>/` (`cover`, `hero`, `process-NN`, `gallery-NN`), `images/about/`.
- After editing anything in `data/`, run `node tools/build.mjs`: it regenerates every HTML shell (head meta from `SITE.seo`, JSON-LD Person/WebSite/ProfilePage, an English crawler fallback inside `<main>` that main.js replaces), `sitemap.xml` and `robots.txt`. Don't hand-edit the HTML files. `work.html` deliberately has no static canonical (main.js adds it per `?id=`).
- Never change a published work `id`, the repo name, or the URL: it is printed as a QR code on business cards.
- Do not add unannounced award results or unverified biography entries. Keep empty sections as `[]`.
- Design rules: white background, black/dark-grey text, no shadows/gradients/rounded buttons, no extra rules or buttons, subtle motion only (respect `prefers-reduced-motion`). The home page should lead with photos: header → PROJECTS → grid.
- Category filters were removed on purpose; `tags`/`category` stay in the data for a possible future filter.
- Preview: `python3 -m http.server 8000` in this folder.
- Commit freely, but never `git push` — the owner always pushes themselves.
- Work only inside this folder; never touch sibling projects (`../pattern-am-cad`, etc.).
